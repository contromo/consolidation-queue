\section{Future Work}

The nearest follow-up is packaging, not another rescue experiment: finish the
figures, tables, claim cross-checks, reproducibility bundle, and external
review pass for an arXiv technical report. The draft should keep every claim
connected to an artifact path and keep unsupported claims visible in the main
limitations section.

Scientifically, the next licensed experiments should be preregistered before
execution. One direction is a policy-facing adapter-contract audit or a fresh
Phase 4 baseline with committed or archived run JSON payloads, so the blocked
CQR cross-tab can be tested without relying on missing artifacts. Another is a
new external-transfer boundary, such as a MemoryAgentBench-style
conflict-resolution adapter, only if the same-stream and same-substrate
invariants can be preserved or the result is explicitly labeled
descriptive-only.

Further LongMemEval work should not be a rerun to rescue the observed X.4
metric. Any extension to LongMemEval-S, LongMemEval-V2, distractor-heavy
retrieval, or additional policy interfaces needs a fresh preregistration,
fixed denominator, PFLC target, judge gate, and abort criteria.
