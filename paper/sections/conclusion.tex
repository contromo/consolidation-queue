\section{Conclusion}

Memory metrics can pass while memory policies fail. The CQ case study
demonstrates this concretely: same-stream evaluation reveals one clean
mechanism-survival row, several bounded nulls, and a stable external-transfer
loss that a single-variable repair and a symmetric falsifier together isolate
as an answer-time interface gap. None of these results would have been visible
to clustering, retrieval, or answer-accuracy scoring alone. The contribution
is the evaluation discipline captured by the four claims: Same-stream
evaluation makes policy attribution inspectable; Standard memory metrics can
pass while policy-facing lookup fails; Preserved negative transfer exposes
interface failures; and A paired repair/control isolates readout cardinality.
These claims are not CQ superiority. The discipline is portable to other
persistent-agent memory
systems; the CQ artifacts and preregistration locks are released as worked
examples of how to apply it.
